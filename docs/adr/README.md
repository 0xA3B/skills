# Decision records

Each file here records one choice that is hard to reverse, surprising without context, and a real
trade-off: the context, the decision, and the reason. Read the records that touch an area before
changing it, and add a record in the same change as the code it explains. The
`engineering:decision-records` skill owns these three conditions, the format, and the supersede
workflow; without the skill, imitate an existing record. Files are numbered `NNNN-slug.md`. A
replaced record carries `status: superseded by ADR-NNNN`, and a record with a `status` shows it in
the index.
