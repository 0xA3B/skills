# Update

## Steps

1. If the section holds its terms in one or more tables, convert each table to the list form in the
   `SKILL.md` section structure, keeping each group's subheading and each term, definition, and
   alias unchanged.
2. Compare the proposed language with existing terminology.
3. Add or revise only terms that are stable enough to guide future work, and remove terms the
   repository no longer uses or that no longer resolve a confusion.
4. Resolve synonyms by choosing one canonical term and listing aliases to avoid.
5. Resolve overloaded words by splitting concepts or flagging the ambiguity in the relevant
   definition.
6. Update relationships when they clarify ownership, lifecycle, or cardinality.

## Final response

End with:

- Terms added, changed, or intentionally deferred.
- The table conversion, when the section held a table.
- Ambiguities resolved or still open.
- Files updated.

Stop when the terminology section reflects the stable language and any remaining ambiguities are
reported.
